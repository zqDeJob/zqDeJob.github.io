# 韩先凯-人生进阶指南

韩先凯（绰号法海）的开放书稿，讲 AI 时代怎么继续学习。仓库在 [byoungd/up](https://github.com/byoungd/up)，在线阅读在 [byoungd.github.io/up](https://byoungd.github.io/up/)。正文按 [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/) 授权，EPUB 和 PDF 在仓库的下载页。

2017 年从一份英语笔记长出来，后来收进 AI、真实项目、创业验证、生活节律和恢复。不保证变厉害，也不要求从第一页读到最后一页。用法是：带着一个真实问题进来，留下现在的起点，做一个小到能做完的动作，记下能复查的证据，过一阵再测一次。AI 可以帮忙拆题、提问和起草；目标、来源、隐私和最后算不算数，仍由人定。

书大致分成六部。第一部是英语，从听、说、读、写接到求职和远程协作。第二部把能力放回生活，写失败、关系、选择和恢复。第三部讲怎么用 AI，判断不外包。第四部把练习带回身体、家庭和每天的安排。第五部是九十天怎么做完，以及九十天以后还验不验得住。第六部是怎么跟自己长期相处。后面还有术语索引、可复制的工作表，以及创业、自律和 AI 工作流的实操。

低谷那一部分是作者自己的记录，不能代替看病。持续的低落、失眠或危险念头，去找当地合格的医疗或心理支持。
