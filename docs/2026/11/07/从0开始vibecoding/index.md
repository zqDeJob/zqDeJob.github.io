# 从 0 开始 Vibecoding

不先写一堆需求文档，直接用感觉搭：先找氛围和参考，再定角色和素材，后面才落到页面和交互。本文边做边记，后面会继续补。

## 第一步：网站构思

先别急着开项目，先把「长什么样、什么感觉」找清楚。

### 去 Pinterest 找感觉

入口：[pinterest.com](https://www.pinterest.com/)

搜关键词（英文通常更好出图），比如：

- `landing page design`
- `portfolio website`
- `dark UI` / `soft pastel web`
- `3D character website`

把对眼的版式、配色、字体气质、留白方式存进自己的看板。这一步不是抄，是给后面跟 Agent 说话时有具体参照：「我想要这种疏朗感 / 这种暗色科技感」。

### 网页特效去 React Bits 淘

入口：[reactbits.dev/get-started/index](https://reactbits.dev/get-started/index)

里面有一批现成的 React 动效、背景、交互组件。构思阶段先逛一圈，记下可能用得上的特效名或截图：

- 背景粒子 / 光晕
- 文字入场、卡片悬浮
- 鼠标跟随、滚动叙事

等真正搭页面时，再让 Agent 按选定的特效接入，比自己从零写 CSS 动画省事很多。

**这一步的产出：** 若干参考图 + 一两句气质描述 + 可选特效清单。

## 第二步：寻找素材（3D 角色）

有了整体气质，再定一个贯穿全站的视觉锚点——比如一个 3D 角色。

### 用豆包做角色设定

工具用 **豆包** 即可。流程大致是：

1. 让 Agent 先帮你写一版「3D 角色设定」提示词（人设、体型、服装、色调、镜头）
2. 在豆包里 **上传风格参考图**（从 Pinterest 存下来的、或自己喜欢的角色图）
3. 说明希望 AI **生成类似风格的角色设定图**（多视图更好：正面 / 侧面 / 3/4 侧）
4. 不满意就改提示词、换参考图，多出几版再定稿

有了稳定的角色设定图，后面做站内插画、加载页、空状态、关于页，都有统一形象可复用。

**这一步的产出：** 角色设定图若干张 + 简短人设说明（名字、性格、用在站里的场景）。

### 用即梦生成一段视频

有了角色设定图之后，再用 **即梦** 把角色「动起来」：

1. 上传上面定稿的 **3D 角色图**
2. 再上传 **任一场景图片**（室内、街道、幻想背景都行，和站点气质沾边最好）
3. 让即梦基于「角色 + 场景」生成一小段视频（镜头缓慢推进、角色轻微动作即可，不必追求长片）

这段视频后面可以当 Hero 背景、加载过渡，或滚动到某一屏时的氛围素材。

**这一步补完后的产出：** 角色设定图 + 角色入镜短视频。

## 第三步：制作网站

关键词：**Three.js** + **html2canvas**，配合前面攒下的参考、特效和素材，把站真正搭出来。

### Three.js：页面里的 3D / 动效层

用 Three.js（常和 React Three Fiber 一起）承接：

- 角色或场景的轻量 3D 展示
- 与滚动、鼠标联动的镜头与粒子
- 和第一步在 [React Bits](https://reactbits.dev/get-started/index) 里看中的动效对接（能复用组件就复用，缺的再用 Three.js 补）

跟 Agent 说清楚：技术栈用 Three.js，视觉对齐 Pinterest 看板，素材用豆包设定图 / 即梦视频。

### html2canvas：把画面「拍」成图

**html2canvas** 可以把当前 DOM（或某一块画布区域）导出成图片，适合：

- 生成分享图、封面截图
- 把动态页某一帧固化成静态资源
- 做「一键导出当前效果」一类的小功能

和 Three.js 搭配时：Three.js 负责实时动效，需要留档或分享时再用 html2canvas（或对 WebGL 画布的截图方案）导出。

### 落地时跟 Agent 怎么说（示例）

```text
用 Three.js + html2canvas 搭一个落地页。
视觉参考我 Pinterest 看板的气质；动效可参考 React Bits。
角色用这张设定图，Hero 可考虑循环这段即梦视频。
先出可滚动的单页结构，再细化交互动效。
```

**这一步的产出：** 可本地跑起来的网站骨架 + 基础动效 + 素材就位。
