# 阴郁疲惫厌世夸张表情提示词

## 01 低压沉默

```text

```

## 02 困倦发呆

```text
眼睛半眯或闭上，嘴巴微张打哈欠，眼神涣散，眉毛下垂，头靠在手上，一副困倦又无精打采的样子。
```

## 03 厌世冷眼

```text
眼神斜视，充满不屑与冷漠，眉毛轻挑又下压，嘴角微抿，脸部线条紧绷，仿佛看透一切，对世界毫无兴趣。
```

## 04 失眠黑眼圈

```text
眼下青黑，眼神疲惫迷离，头发凌乱，手扶额头，嘴唇无力下垂，整个人憔悴不堪，透露出长夜未眠的疲惫感。
```

## 05 灵魂下线

```text

```

## 06 心累叹气


```text

```

## 08 无力垂眼

```text

```

