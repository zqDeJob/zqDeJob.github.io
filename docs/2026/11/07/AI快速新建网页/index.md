# AI快速新建网页

用 AI 从想法到可看网页，别一上来就让它「直接写个官网」。更稳的做法是：**先问清项目 → 再搭骨架 → 最后填图微调**。

## 第一步：让 AI 先提问，别急着写代码

不要直接让 AI 写网页，也不要一上来就丢一堆参考图。

让 AI **主动提项目相关问题**，你逐一回答；不会的可以跳过。靠 AI 把模糊想法梳理成逻辑清晰的完整项目。

可以这样开场：

```text
我想做一个网页，但需求还不清晰。
请先只问项目相关问题（目标用户、核心功能、页面结构、风格偏好等），
不要写代码。我逐条回答，答不上来的会跳过。
```

## 第二步：给视觉参考，但要求分析而不是照搬

提供视觉参考时，明确要求：**分析参考的视觉语言**（配色、排版、留白、层级），结合项目定位，生成 **带预留图片位** 的结构化网页骨架。

```text
这是视觉参考（仅作气质参考，不要照搬）：
[贴图或链接]

请分析其视觉语言，结合我们刚确认的项目定位，
输出带图片占位的网页骨架（可用 HTML/React），先不要填真实素材。
```

## 第三步：图片丢给 Codex，自动对位

把所有图片放到 **同一个文件夹**，交给 Codex：让 AI 自动识别、分类，并匹配到对应网页模块。出错时通常只需少量调整个别图片。

```text
图片都在这个文件夹里：[路径]
请识别每张图适合哪个模块，填进骨架对应位置。
对不上的先标出来，我再微调。
```

## 核心思路

先搭骨架 → 再填素材 → 最后微调。

不用一开始就追求完美。
