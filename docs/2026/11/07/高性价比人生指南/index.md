# 高性价比人生指南

一本按中国大陆现行规定写的备选单，34 节、772 条。每条写清花掉什么、换回什么、证据有多硬。不用全做，挑走一两条就算数。法律、医保、社保以当地部门和原文为准。

在线检索：<https://eternity4719.github.io/HowToLiveBetter/>

下面 34 节是二级目录。每节保留原文的分组说明，以及每一条的「说人话」、成本和证据等级。收益栏的原始数字和文献仍在仓库里。

## 每条在算什么

想多留住的东西只有四样，彼此不互相折算：寿命、时间与精力、金钱、人身自由。好处先算到自己身上，其次是配偶和直系亲属，再往后是朋友同事，最后才是陌生人。

证据分三档。A 是有具体数字，出处是荟萃分析、大型队列或随机试验；法律和政策类的 A 指引到了法条或官方文件。B 是有研究但说不出确切数字。C 是经验或公认做法。另外有个性价比档，极高的大约 123 条，那一档是作者自己的判断，不算证据。

百分比多半是「比没做的人低几成」，不是每一百人里少几个。

## 怎么查

打开在线检索，可以按关键词、章节、证据等级筛，也可以按花不花钱、花多少时间、要不要毅力来叠。只看结论最硬的，勾证据等级 A。只看最值得做的，勾性价比「极高」。

[生活自查](https://eternity4719.github.io/HowToLiveBetter/selfcheck.html) 是几十道是否题，用来看哪些事还没做。
