# 阿里云 + 七牛云海外节点图床搭建教程

给 Obsidian 配一套自己的图床：**阿里云管域名解析，七牛云存图片，PicGo 负责上传**。

海外节点（亚太新加坡）的好处是**域名不需要 ICP 备案**，国内访问会慢一点，但笔记自用完全够。

> 适用场景：域名 `img.*****.cn` + 七牛海外存储 + PicGo 上传 + Obsidian 笔记嵌图  
> 前置准备：阿里云域名、七牛云账号、PicGo  
> ⚠️ 防盗链一定要配，否则流量被人盗刷，账单自己扛

## 整体链路

```text
截图 / 粘贴图片
      │
      ▼
   PicGo（七牛云图床配置）
      │  上传 + AK/SK 签名
      ▼
 七牛对象存储（桶 img-*****，区域 as0 亚太新加坡）
      │
      ▼
 自定义域名 img.*****.cn（CDN + 防盗链）
      │
      ▼
 Obsidian 自动插入 markdown 图片链接
```

DNS 这条线另算：阿里云把 `img.*****.cn` 的 CNAME 指向七牛给的 `xxx.qiniudns.com`，并用一条 TXT 记录完成域名所有权验证。

## 阶段 1：七牛云创建存储桶

1. 登录七牛控制台 → 对象存储 → 新建空间
2. 空间名称（桶名，后面 PicGo 要用）：`img-*****`
3. 存储区域：**亚太新加坡 as0**（海外，免备案）
4. 访问控制：**公开**（图床必须公开，否则图片打不开）
5. 确定创建
6. 右上角头像 → 密钥管理，复制保存：
   - AccessKey（AK）
   - SecretKey（SK）

![七牛云控制台里的存储桶配置](/img/posts/qiniu/qiniu-bucket.png)

> ⚠️ 密钥不要发给别人，有扣费风险

## 阶段 2：添加自定义域名

1. 对象存储 → 域名管理 → 添加域名
2. 域名：`img.*****.cn`
3. 协议：先选 HTTP（后面可选升级 HTTPS）
4. 业务类型：图片 / 小文件
5. 空间：选中刚才创建的 `img-*****`
6. 提交，进入域名所有权验证
7. 验证方式选 **DNS 解析验证**
8. 按七牛提示拿到 TXT 记录，**去阿里云添加这条 TXT 记录**（具体操作见阶段 3）
9. TXT 记录加好后，等几分钟，七牛自动核验
10. 核验通过后页面会生成一条 CNAME，格式类似：
    `*****.qiniudns.com`

> 这个就是要填到阿里云解析的 CNAME 值

![七牛云域名管理里的自定义域名配置](/img/posts/qiniu/qiniu-domain.png)

## 阶段 3：阿里云域名解析配置

进入阿里云域名控制台 → 解析 → 添加记录，一共两条：

### 第一条：TXT 记录（域名所有权验证用）

七牛提交自定义域名后会给你一段 TXT 验证信息，按它填：

| 记录类型 | 主机记录                          | 记录值                     |
| -------- | --------------------------------- | -------------------------- |
| TXT      | `verification`（以七牛给的为准） | 七牛给出的一长串验证文本   |

> 这条记录是给七牛核验「这个域名确实是你自己的」用的，加完等几分钟，七牛页面会自动变成验证通过。

### 第二条：CNAME 记录（真正指向七牛）

| 记录类型 | 主机记录 | 记录值                    | TTL      |
| -------- | -------- | ------------------------- | -------- |
| CNAME    | `img`    | `*****.qiniudns.com`      | 10 分钟 |

> 验证用的 TXT 记录，验证成功后可以保留，也可以删掉，不影响解析。

自查命令（CMD 直接运行）：

```bash
nslookup -type=CNAME img.*****.cn
```

输出和上面的 CNAME 一致，代表解析生效。接着等七牛检测，状态变为【已配置 / 成功】。

![域名解析记录配置](/img/posts/qiniu/dns-record.png)

## 阶段 4：CDN 防盗链配置

进入域名 `img.*****.cn` → 配置 → 防盗链：

1. 防盗链开关：开启
2. 校验方式：Referer 白名单
3. ✅ **勾选【允许空 Referer】（重中之重！Obsidian 本地打开图片没有 referer，不勾直接裂图）**
4. Referer 白名单，直接复制下面粘贴：

```text
obsidian://
localhost
127.0.0.1
```

5. 不勾选「允许 Referer 为空时放行所有请求」（只空 Referer 放行，别的网站盗链照样拦）
6. 保存

> 额外推荐：配置 → 告警配置，设置流量阈值（比如 10GB），超额短信提醒，避免巨额账单。

## 阶段 5：PicGo 配置

打开 PicGo → 图床设置 → 七牛云：

```text
AccessKey：【粘贴你的AK】
SecretKey：【粘贴你的SK】
存储空间：img-*****
存储区域：as0 亚太新加坡
自定义域名：http://img.*****.cn
存储路径：/
```

- 存储路径：留 `/` 就行，图片直接落在桶根目录。想分文件夹就填 `img`，链接会变成 `http://img.*****.cn/img/xxx.png`
- 后缀名：留空
- 开启【时间戳重命名】（推荐，避免同名图片覆盖）；配合自定义前缀 `img`，文件名形如 `img20261113224510206.png`

👉 测试：PicGo 上传一张图片，复制链接，浏览器直接打开，能显示 = 成功。

实测上传出来的真实链接长这样（`/` + `/` 拼出双斜杠，不影响访问）：

```text
http://img.*****.cn//img20261113224510206.png
http://img.*****.cn//img20261113224019287.png
```

## 阶段 6：Obsidian 联动

1. Obsidian 安装插件：`Image auto upload Plugin`，或者直接用 PicGo 剪贴板监听
2. PicGo 开启：监听剪贴板、上传后自动复制链接
3. Obsidian 设置：图片粘贴时走 PicGo 上传，自动插入 markdown 图片

```markdown
![图片说明](http://img.*****.cn//img20261113224510206.png)
```

## 可选进阶：升级 HTTPS

1. 阿里云 SSL 证书控制台 → 免费 DV 证书，申请域名 `img.*****.cn`
2. 证书下发后，下载 Nginx 版本证书
3. 回到七牛域名配置 → HTTPS，上传证书 + 私钥
4. 强制 HTTPS（可选）
5. PicGo 自定义域名改成：`https://img.*****.cn`

## 清理与避坑清单

1. 七牛自带测试域名（如 `*****.gdipper.com`）：停用，防止误传扣费
2. 不要关闭【允许空 Referer】，Obsidian 本地看图必炸
3. 海外节点国内访问会慢，适合笔记自用，不适合公开网站
4. 密钥不要分享，也不要写进笔记
5. 图片别传超大文件，七牛海外有流量费用

## 故障自查命令

```bash
# 查 CNAME 解析是否生效
nslookup -type=CNAME img.*****.cn

# 测试图片连通（替换成你的真实图片链接）
curl -I http://img.*****.cn/img/test.png
```

常见症状对照：

| 症状                            | 大概率原因                              |
| ------------------------------- | --------------------------------------- |
| 图片在 Obsidian 里裂图          | 防盗链没勾「允许空 Referer」             |
| PicGo 上传报签名错误            | AK/SK 填错，或桶名/区域不对             |
| 浏览器打不开、返回 403          | 防盗链 Referer 拦截，或桶未设公开        |
| 链接能开但很慢                  | 海外节点 + 未开 CDN 加速                 |
| 链接 404                        | CNAME 没生效，或存储路径与链接前缀不一致 |
